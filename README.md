# Мое_граббер

Сайт-браузер для скачивания фото с других сайтов. Версия **1.0.0**.

**Открыть:** https://drakkkkon.github.io/Moe_nakleyki/ (если репозиторий переименовать в `Moe_grabber`, адрес станет https://drakkkkon.github.io/Moe_grabber/ — внутри всё на относительных путях, ничего чинить не придётся).

## Что умеет

- Встроенный браузер: адресная строка с поиском (Bing, DuckDuckGo, Google, Яндекс), вкладки, назад/вперёд, закладки, история.
- Три режима показа: «Быстро» (без скриптов сайта), «Полностью» (со скриптами), «Напрямую» (как в Chrome).
- Кнопка «Фото» находит все картинки страницы: обычные, «ленивые», srcset (берётся самый крупный размер), фоны CSS, обложки og:image, постеры видео, SVG-рисунки, ссылки на фото и фото, спрятанные в данных страницы.
- Меню выбора картинок: фильтр по формату (JPG, PNG, WEBP, GIF, SVG, AVIF, BMP, ICO, TIFF, HEIC), скрыть мелкие, сортировка по размеру, просмотр крупно. Долгое нажатие на картинку на сайте сразу выбирает её.
- Скачивание: сначала напрямую, потом через прокси. Если сайт фото не отдаёт — делается **скриншот** (microlink, thum.io, mShots).
- Всё складывается в **ZIP**: `Фото/` — оригиналы «как есть», `Скриншоты/` — отдельно, по желанию копии в JPG/PNG/WEBP и скриншот всей страницы, плюс `список.txt` и `не скачались.txt`.
- Выбор, куда сохранить: окно сохранения (компьютер), «Поделиться» (Android: Файлы, Диск, Telegram…) или «Загрузки».
- Общий аккаунт моих сайтов (Firebase): настройки, закладки и история в облаке.
- Устанавливается как приложение; принимает ссылки через «Поделиться».

## Файлы

`index.html`, `css/style.css`, `js/app.js` (интерфейс), `js/grab.js` (сеть, поиск картинок, скриншоты), `js/zip.js` (ZIP), `js/mm-account.js` (общий аккаунт), `sw.js`, `manifest.webmanifest`, `icons/`.
