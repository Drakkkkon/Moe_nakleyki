# Мое_наклейки

Сайт-приложение для печати термонаклеек на принтерах **Xprinter** с телефона Android по USB-кабелю (через переходник OTG). Не требует установки драйверов и приложений.

**Открыть:** https://drakkkkon.github.io/Moe_nakleyki/ (в Google Chrome)

## Что умеет

- Текст (размер, жирный, выравнивание, белым по чёрному), картинки из галереи или камеры, QR-коды, штрихкоды Code 128 и EAN-13, рамка.
- Любой размер наклейки, копии, шаблоны и готовые примеры.
- Принтеры наклеек (язык TSPL: XP-365B, XP-420B, XP-470B и похожие) и чековые (ESC/POS: XP-58, XP-80).
- Работает без интернета после первого открытия. После «Добавить на главный экран» фото и ссылки можно отправлять сюда через «Поделиться».

## Как подключить

1. Переходник OTG (штекер как у телефона → гнездо USB) + обычный USB-кабель принтера.
2. Включить принтер, подключить к телефону, открыть сайт в Google Chrome.
3. Нажать «Подключить принтер» и выбрать принтер в списке.

Подробная инструкция и решение проблем — в приложении: «Настройки» → «Инструкции».

## Аккаунт (с 1.1.0)

«Настройки» → «Аккаунт»: вход по почте и паролю, один аккаунт на все мои сайты (My Money, iLife, Геометрия Полки, Мое_коровы, My_topsecret, Мое_наклейки). Шаблоны, текущая наклейка, настройки печати и тема хранятся в облаке (Firebase) и сами переходят между телефоном и компьютером. Подключение к принтеру у каждого телефона своё. Код: `js/mm-account.js`.
