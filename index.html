      Инструкции и ссылки
      Программа для Windows

      В программе внутри настоящий Chrome: сайты открываются как обычно, прокси не нужны, фото скачиваются напрямую, скриншоты делает сама программа. Правый клик по картинке → «Скачать эту картинку…».

      Клавиши: Ctrl+T — новая вкладка, Ctrl+W — закрыть, Ctrl+L — адресная строка, F5 — обновить, Alt+← / Alt+→ — назад/вперёд.

      Новые версии: Мое_сайты → Мое_граббер.

      Как скачать фото
      1. Наберите адрес сайта или запрос в строке сверху (кнопка «Картинки» на главной ищет сразу фото).
      2. Нажмите круглую кнопку «Фото» внизу справа — откроется список всех картинок страницы.
      3. Отметьте нужные (по умолчанию отмечены все крупные), можно отфильтровать по формату: JPG, PNG, WEBP, GIF, SVG, AVIF…
      4. «Скачать» — фото соберутся в ZIP, затем выберите, куда его сохранить.
      5. Долгое нажатие на картинку на сайте сразу открывает выбор с ней одной.
      Что внутри архива
      • Фото — оригиналы «как есть», байт в байт как на сайте.
      • Скриншоты — снимки тех фото, которые сайт не отдал (защита от скачивания).
      • Фото (JPG/PNG/WEBP) — копии в выбранном формате, если включено в настройках.
      • Скриншот страницы — снимок всей страницы, если отмечено.
      • Если фото пришло через wsrv.nl, оно может быть пересжато — это отмечено в списке.
      • список.txt — откуда взят каждый файл; не скачались.txt — ссылки на то, что не удалось.
      Как выбрать папку на телефоне

      Кнопка «Отправить или сохранить в…» открывает меню Android: можно выбрать «Файлы», Google Диск, Telegram и т. д.

      Чтобы Chrome спрашивал папку и для «В „Загрузки“»: Chrome → ⋮ → Настройки → Скачанные файлы → «Спрашивать, где сохранять файлы».

      На компьютере (Chrome, Edge) кнопка «Выбрать папку и имя…» открывает обычное окно сохранения.

      Почему сайт открылся не так или пусто

      «Быстро» показывает страницу без её скриптов: это быстро и надёжно, но сайты-приложения (Instagram, Pinterest и т. п.) могут быть пустыми. Тогда в меню ⋮ выберите «Полностью» или «Напрямую». В режиме «Напрямую» часть сайтов запрещает показ внутри другого сайта — откройте их в Chrome, скопируйте адрес нужного фото и вставьте сюда.

      Если не открывается ничего — проверьте прокси в настройках («Проверить»).

      Свой прокси на Cloudflare (бесплатно, самый надёжный)

      Общие бесплатные прокси работают со сбоями: лимиты, блокировки по IP, закрытия. Свой прокси на Cloudflare бесплатен (до 100 000 запросов в день) и работает только для вашего граббера.

      1. Откройте dash.cloudflare.com и зарегистрируйтесь (почта и пароль).
      2. Слева «Compute (Workers)» → «Workers & Pages» → «Create» → «Start with Hello World» → придумайте имя (например grabber) → «Deploy».
      3. Нажмите «Edit code», удалите весь код и вставьте код ниже (кнопка «Копировать»), затем «Deploy».
      4. Скопируйте адрес вида https://grabber.ваше-имя.workers.dev.
      5. Здесь, в поле «Прокси», добавьте первой строкой: https://grabber.ваше-имя.workers.dev/?url={u} и нажмите «Проверить».
      // Прокси для «Мое_граббер»: отдаёт чужие страницы и фото только сайтам drakkkkon.github.io
const ALLOWED = ["https://drakkkkon.github.io"];
export default {
  async fetch(req) {
    const origin = req.headers.get("Origin") || "";
    const cors = {
      "Access-Control-Allow-Origin": origin || "*",
      "Access-Control-Allow-Methods": "GET, HEAD, OPTIONS",
      "Access-Control-Allow-Headers": "*",
      "Vary": "Origin"
    };
    if (req.method === "OPTIONS") return new Response(null, { headers: cors });
    if (origin && !ALLOWED.includes(origin)) return new Response("Not allowed", { status: 403, headers: cors });
    const url = new URL(req.url).searchParams.get("url");
    if (!url || !/^https?:\/\//i.test(url)) return new Response("Use ?url=https://...", { status: 400, headers: cors });
    let r;
    try {
      r = await fetch(url, { redirect: "follow", headers: {
        "User-Agent": "Mozilla/5.0 (Linux; Android 14) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/131.0 Mobile Safari/537.36",
        "Accept": "text/html,application/xhtml+xml,image/avif,image/webp,image/*,*/*;q=0.8",
        "Accept-Language": "ru-RU,ru;q=0.9,en;q=0.8"
      } });
    } catch (e) {
      return new Response("Fetch failed: " + e.message, { status: 502, headers: cors });
    }
    const h = new Headers(r.headers);
    for (const k in cors) h.set(k, cors[k]);
    ["content-security-policy", "x-frame-options", "set-cookie", "content-encoding", "content-length"].forEach(k => h.delete(k));
    return new Response(r.body, { status: r.status, headers: h });
  }
};
      Установить как приложение

      Chrome → ⋮ → «Добавить на главный экран». После этого в Chrome в меню «Поделиться» появится «Мое_граббер» — ссылка сразу откроется здесь.
